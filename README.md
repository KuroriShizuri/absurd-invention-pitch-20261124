One sentence, 125 characters: a houseplant that texts your boss to request a sick day for itself every time you forget to water it for three days straight.

## Run it

```sh
python3 main.py --self-test
python3 main.py
```

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it against the gate (1–220 characters, single line, single sentence, not only white space), and reads it back to confirm the file holds exactly the entry. Standard library only, deterministic, no network, no clock.

## How the judge reads it

The pitch is judged on three qualities — **funny**, **clever**, and **original** — behind a hard gate: the file must hold one sentence of 1–220 characters. The houseplant pitch clears the gate at 125 characters and earns its keep on the joke itself: a plant that calls in sick for itself, turning a neglected chore into office bureaucracy.
